# Smart Agro Rover Tools

This directory contains development and testing utilities.

Possible tools include:

* ESP32 connection tester
* API testing scripts
* Sensor calibration tools
* Serial monitoring utilities
* Dashboard testing utilities
* Data logging tools

## Recommended future tools

```text
tools/
├── api_test.py
├── sensor_calibration.py
├── serial_monitor.py
└── data_logger.py
```

These tools should be used during development and testing without being part of the main ESP32 firmware.
