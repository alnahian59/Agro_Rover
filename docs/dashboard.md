# Dashboard Documentation

The Smart Agro Rover dashboard is a responsive web interface.

## Dashboard Sections

### Connection

Displays whether the rover is online.

### Rover Control

Controls:

* Forward
* Reverse
* Left
* Right
* Stop

### Agricultural Operations

Controls:

* Seed dispensing
* Water pump
* Medicine spray pump

### Monitoring

Displays:

* Soil moisture
* Distance
* Operating mode
* Pump states
* Seed system state

## Technologies

* HTML5
* CSS3
* JavaScript
* REST API
